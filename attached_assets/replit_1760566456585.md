# AI JobBot - Production-Grade Career Automation SaaS

## Overview

AI JobBot is a **production-ready** career automation SaaS platform that leverages local AI (Ollama) to streamline job searching and application processes. The application combines intelligent CV parsing, multi-platform job scraping (LinkedIn, Indeed, Glassdoor), AI-powered cover letter generation, and automated job applications with human-in-the-loop CAPTCHA handling. Built with a Steve Jobs-inspired design philosophy featuring the Palestine color palette (red #E53E3E, turquoise #00F0FF, green #00FF88), glassmorphism effects, and 60fps animations.

The platform operates on a freemium model with a credit system (5 free credits on signup) and is designed for scalability with production-ready features including Stripe integration readiness, GDPR compliance, and comprehensive analytics tracking.

**Status:** ✅ MVP Complete - All core features implemented and tested (October 2025)

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture

**Design System**: The application implements a design-first approach with consistent visual language across all pages:
- **Palestine Color Palette**: Three-circle animated logo using red (#E53E3E), turquoise (#00F0FF), and green (#00FF88)
- **Glassmorphism**: Semi-transparent cards with backdrop blur effects for modern depth
- **60fps Animations**: Custom cursor effects, starfield background, pulsing logo animations
- **Responsive Layout**: Mobile-first approach with breakpoints for tablet and desktop

**Template Architecture**: Jinja2 templating with modular components:
- Base template (`includes/base.html`) with global layout and scripts
- Reusable sidebar navigation (`includes/sidebar.html`)
- Consistent footer with business card (`includes/footer.html`)
- Page-specific templates extending base (dashboard, job search, CV upload, etc.)

**Client-Side State Management**: Vanilla JavaScript with fetch API for AJAX interactions:
- `app.js`: Main application logic (job search, CV upload, apply actions)
- `consultant.js`: AI chat interface with Zby consultant
- `toast.js`: Global notification system
- `cursor.js` and `stars.js`: Visual enhancements

**Internationalization**: Built-in i18n system supporting English (default) and French:
- Translation keys managed in `config/translations.py`
- Language toggle in navbar
- `<html lang="{{ current_lang }}">` for proper locale detection

### Backend Architecture

**Web Framework**: Flask 3.0 with session-based authentication:
- Routes for all core features (dashboard, job search, CV upload, letter generation, applications)
- API endpoints for AJAX operations (`/api/search-jobs`, `/api/parse-cv`, `/api/consult`, `/api/apply`)
- RESTful design with JSON responses

**Authentication & User Management**:
- Session-based authentication using Flask sessions
- Password hashing with bcrypt (via passlib)
- User profile storage in JSON files (`data/users.json`)
- Demo account pre-configured (`demo@aijobbot.com` / `demo123`)

**Core Modules**:

1. **Profile Manager** (`src/profile_manager.py`):
   - User CRUD operations (create, authenticate, update, delete)
   - Credit system management (use_credits, add_credits)
   - Application tracking (add_application, get_user_stats)
   - GDPR-compliant data deletion

2. **CV Parser** (`src/cv_parser.py`):
   - Supports PDF (PyPDF2) and DOCX (python-docx) formats
   - Extracts text from documents
   - AI-powered structured data extraction (name, skills, experience, education)
   - Integrates with Ollama for intelligent parsing

3. **Letter Generator** (`src/letter_generator.py`):
   - AI-driven personalized cover letter creation
   - Matches CV data with job requirements
   - Exports to DOCX and TXT formats
   - Stores generated letters in `data/generated/cover_letters/`

4. **Scraper Manager** (`src/scraper_manager.py`):
   - Unified interface for multi-platform job searching
   - Coordinates hybrid scraper for Indeed, Glassdoor, LinkedIn
   - Match score calculation based on CV skills vs job requirements
   - Deduplication of results across platforms

5. **Auto-Apply System** (`src/auto_apply/`):
   - Base automation framework (`base_auto_apply.py`) with Selenium WebDriver
   - Platform-specific implementations (LinkedIn, Indeed, Glassdoor)
   - **Human-in-the-loop CAPTCHA handling**: Runs in headful mode, pauses for user interaction
   - Session persistence for login state management
   - Safe element interaction with explicit waits and error handling

6. **AI Client** (`src/ai_client.py`):
   - Unified wrapper for Ollama API interactions
   - Single configurable model (env: `OLLAMA_MODEL`, default: `mistral`)
   - Supports CV parsing, letter generation, and consultant chat
   - Temperature control for response creativity

**Job Scraping Architecture**:
- Hybrid scraper strategy combining multiple sources
- BeautifulSoup4 for HTML parsing
- Requests with custom user agents to avoid blocking
- Rate limiting and random delays to prevent detection
- Match score algorithm comparing user skills with job requirements

**Auto-Apply Flow**:
1. User selects job and clicks "Apply"
2. Platform detected from job URL
3. Selenium driver launches in headful mode
4. Navigate to job page
5. **CAPTCHA Detection**: Check for security challenges
6. If CAPTCHA found: pause, save session, prompt user to solve manually
7. If no CAPTCHA: proceed with form filling
8. Fill application fields using CV data
9. Submit or return control to user for final review

### Data Storage Solutions

**Current Implementation** (Development/MVP):
- **JSON Files**: User profiles, applications, activity logs stored in `data/` directory
- **File System**: Uploaded CVs in `data/uploads/`, generated letters in `data/generated/cover_letters/`
- **Session Files**: Browser sessions for auto-apply in `data/sessions/`

**Production Migration Path**:
- **PostgreSQL**: Recommended for user profiles, applications, analytics
- **Redis**: Session management and caching
- **S3/Cloud Storage**: CV uploads and generated documents
- **Background Workers**: Celery or similar for async job scraping and application processing

**Data Models** (Currently JSON-based):
```python
User: {
    username, email, password_hash, location, experience_years,
    credits, cv_data, cv_uploaded, created_at, applications[]
}

Application: {
    job_url, title, company, location, platform, status,
    match_score, applied_at
}

Activity: {
    user_email, action, description, timestamp, metadata
}
```

### Authentication and Authorization

**Current System**:
- Session-based auth with Flask's built-in session management
- Password hashing using bcrypt (passlib library)
- Credential encryption for stored platform logins (Fernet symmetric encryption)
- No JWT or OAuth (can be added for API access)

**Security Measures**:
- HTTPS required in production (configured via `render.yaml`)
- Password strength validation on frontend
- XSS protection via Jinja2 auto-escaping
- CORS enabled for specified origins
- File upload restrictions (16MB max, PDF/DOCX only)

**User Flow**:
1. Registration with email validation (live AJAX check for duplicates)
2. Optional CV upload during signup
3. 5 free credits granted
4. Session-based authentication for subsequent requests
5. Logout clears session
