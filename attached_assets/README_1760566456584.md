## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- [Ollama](https://ollama.com) installed locally
- Chrome/Chromium browser (for auto-apply)

### Installation

1. **Clone and enter directory**
```bash
git clone <your-repo-url>
cd AI_JobBot
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
```

3. **Set up environment**
```bash
cp .env.example .env
# Edit .env and configure:
# - OLLAMA_MODEL=mistral (or your preferred model)
# - SECRET_KEY=your-secret-key
# - STRIPE keys (for monetization)
```

4. **Install Ollama model**
```bash
ollama pull mistral
# Or another model: llama3, codellama, etc.
```

5. **Run the application**
```bash
python app.py
```

6. **Access at** `http://localhost:5000`

## 🔧 Configuration

### Changing AI Model

Edit `.env`:
```env
OLLAMA_MODEL=mistral
```

Supported models:
- `mistral` - Fast, balanced (recommended)
- `llama3` - Larger, more capable
- `codellama` - Optimized for code
- Any Ollama-compatible model

### Customizing Zby's Personality

Edit `src/ai_client.py` line 133:
```python
system_prompt = """You are Zby, an AI career consultant..."""
```

Change tone, add domain expertise, or localize for your market.

### Credit Costs

Edit `.env`:
```env
FREE_CREDITS_ON_SIGNUP=5
CREDIT_COST_PER_APPLY=1
CREDIT_COST_PER_LETTER=1
```

## 🏗️ Architecture

### Project Structure
```
AI_JobBot/
├── app.py                          # Flask application
├── src/
│   ├── ai_client.py                # Unified Ollama wrapper
│   ├── profile_manager.py          # User authentication & data
│   ├── cv_parser.py                # Resume parsing
│   ├── letter_generator.py         # Cover letter generation
│   ├── scraper_manager.py          # Job search coordinator
│   ├── scrapers/
│   │   └── hybrid_scraper.py       # Multi-platform scraping
│   └── auto_apply/
│       ├── base_auto_apply.py      # Base automation + CAPTCHA
│       ├── linkedin_apply.py       # LinkedIn-specific
│       └── apply_manager.py        # Application coordinator
├── templates/                      # Jinja2 HTML templates
├── static/                         # CSS, JavaScript, assets
├── config/
│   └── translations.py             # i18n translations
└── data/                           # SQLite, uploads, sessions
```

### Tech Stack

**Backend:**
- Flask 3.0 - Web framework
- Ollama - Free local AI (no API costs!)
- Selenium 4 - Web automation
- PyPDF2 - PDF parsing
- Python-docx - DOCX generation
- Cryptography - Credential encryption
- Passlib - Password hashing

**Frontend:**
- Vanilla JavaScript (no framework overhead)
- Custom CSS with Palestine palette
- SVG animations
- Progressive Web App ready

**Database:**
- SQLite (MVP) - File-based, zero config
- PostgreSQL-ready schema (production)
